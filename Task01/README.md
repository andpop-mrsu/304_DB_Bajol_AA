# Лабораторная работа 1. Подготовка окружения для выполнения заданий и интерактивной работы с СУБД SQLite
## Описание файлов

### Исходные данные
- **ratings.csv** - файл с оценками пользователей фильмов. Содержит следующие колонки:
  - `userId` - идентификатор пользователя
  - `movieId` - идентификатор фильма
  - `rating` - оценка (от 0.5 до 5.0)
  - `timestamp` - временная метка оценки

### Результаты выполнения
- **ratings_count.txt** - файл с результатами анализа:
  - Строка 1: минимальный userId и количество его оценок
  - Строка 2: максимальный userId и количество его оценок
  
- **sqlite.txt** - информация об установленной СУБД SQLite:
  - Версия SQLite
  - Доступные режимы вывода данных
