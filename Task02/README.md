# Лабораторная работа 2. Подготовка скриптов для создания таблиц и добавления данных 

## Требования к окружению
Для корректной работы скрипта `db_init.bat` на компьютере должны быть установлены:
1. **Python 3.x** (добавлен в переменные окружения PATH, чтобы вызываться командой `python`).
2. **SQLite** (утилита командной строки `sqlite3` должна быть доступна в PATH).

## Структура файлов
- `make_db_init.py` — кроссплатформенная утилита на Python, которая читает исходные данные из папки `../dataset`, преобразует их (например, извлекает год из названия фильма) и генерирует SQL-скрипт `db_init.sql`.
- `db_init.bat` — shell-скрипт для запуска процесса. Содержит шебанг `#!/bin/bash` для совместимости с Linux и выполнения требования по установке прав через Git.
- `db_init.sql` — сгенерированный файл с командами `DROP`, `CREATE` и `INSERT` (создается автоматически).
- `movies_rating.db` — итоговая база данных SQLite (создается автоматически).

## Как запустить
1. Убедитесь, что вы находитесь в папке `Task02`.
2. Запустите файл:
   - В Windows: `db_init.bat`
   - В Linux/macOS: `./db_init.bat` (предварительно убедившись, что файл имеет права на исполнение).
3. Скрипт отработает за время < 2 секунд, создаст или обновит базу данных `movies_rating.db`.
